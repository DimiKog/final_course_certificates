# 🎓 Certificate NFT Μαθήματος Blockchain & Web3

Αυτό το repository συνοδεύει το πανεπιστημιακό μάθημα
**Blockchain & Web3 Fundamentals** και παρουσιάζει τον σχεδιασμό
ενός **Certificate NFT (Proof of Participation)**.

## ❓ Τι είναι το Certificate NFT
- On-chain απόδειξη συμμετοχής στο μάθημα
- Συνδέεται με wallet (ψηφιακή ταυτότητα)
- Είναι επαληθεύσιμο και μη αλλοιώσιμο
- Δεν αποτελεί βαθμό ή επίσημο δίπλωμα

## ❌ Τι ΔΕΝ είναι
- Δεν είναι συλλεκτικό NFT
- Δεν αντιπροσωπεύει ECTS ή αξιολόγηση
- Δεν περιέχει προσωπικά δεδομένα

## 🧠 Εκπαιδευτική Λογική
Το Certificate NFT αποτελεί την πρακτική σύνδεση:
- του πειράματος blockchain χωρίς κώδικα
- με την έννοια των smart contracts και των NFTs (ERC-721)

## 📁 Περιεχόμενα Repository
- `metadata/` → το περιεχόμενο του NFT (JSON)
- `assets/` → οπτική αναπαράσταση του certificate
- `mint-flow.md` → πώς δημιουργείται (conceptual)
